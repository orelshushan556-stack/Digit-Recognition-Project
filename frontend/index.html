About the Model & Expectations

This engine is powered by a custom Fully-Connected Neural Network written from scratch in native C++ and compiled to WebAssembly. It was trained on the MNIST dataset (60,000 standard handwritten digits).

Please Note: Unlike a modern Convolutional Neural Network (CNN), a dense architecture lacks spatial invariance. While this drawing pad runs a pre-processing algorithm to automatically center and scale your input, unconventional drawing styles, extreme line thicknesses, or non-standard digit shapes may still result in lower accuracy.

Behind the Scenes

🚀 100% Engineered From Scratch

This project features a neural network engine built entirely without external machine learning libraries. The engineering complexity spans three core pillars:

  • Native C++ Implementation: Independent implementation of all required mathematics, including matrix multiplication, backpropagation algorithms, and activation functions (ReLU & Softmax).
  • Hardware-Level Optimization: To maximize performance, matrix data is managed via a manually calculated 1D Flat Array rather than standard 2D arrays. This architectural choice optimizes CPU cache utilization and ensures efficient memory management.
  • WebAssembly Runtime: The system-level C++ code is compiled to Wasm, allowing the heavy model inference to execute entirely client-side within the browser at near-native speeds.
